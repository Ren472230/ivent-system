# IVENT SYSTEM

IVENT SYSTEM – автономная система для домашних мероприятий, дней рождения и игровых вечеров. Она связывает игроков, этапы, жетоны, магазин, предметы, библиотеку игр, аукцион, сохранения и итоговую статистику в один сценарий.

## Готовый запуск

Для проведения вечера нужен один файл:

`release/ivent-system.html`

1. Скачайте файл на компьютер.
2. Откройте его двойным щелчком в Chrome или Edge.
3. Введите название мероприятия и минимум 3 игроков.
4. Нажмите «Создать вечер».

Интернет для базовых функций не требуется.

## Паспорт игры

Каждая игра описывается через единый набор параметров:

- название и обложка;
- короткая суть;
- цель;
- подробные правила;
- минимум и максимум игроков;
- длительность;
- формат;
- способ определения результата;
- награда;
- политика предметов;
- реквизит;
- возможности ИИ;
- заметки ведущему;
- теги.

Игра является шаблоном. Этап является конкретным использованием этого шаблона в мероприятии.

Редактирование пользовательской игры создаёт новую редакцию с новым техническим идентификатором. Старые этапы продолжают ссылаться на предыдущую редакцию, поэтому изменение правил не переписывает историю уже подготовленного или проведённого вечера.

## Библиотека и архив

Активная игра видна при добавлении нового этапа.

Архивная игра остаётся сохранённой в библиотеке и в исторических этапах, но исчезает из обычного выбора новых этапов. Её можно восстановить одним действием.

Системные игры можно архивировать и дублировать. Пользовательские игры дополнительно можно редактировать с созданием новой редакции.

## Картинки

Обложка игры использует формат 16:9.

При загрузке собственного изображения браузер локально:

1. читает выбранный файл;
2. обрезает изображение по центру под 16:9;
3. уменьшает его до 800×450;
4. сохраняет обработанную копию внутри библиотеки.

Изображение никуда не отправляется. Если картинка отсутствует, система создаёт встроенную SVG-обложку автоматически.

## Базовый сценарий вечера

При создании нового мероприятия система автоматически добавляет программу:

1. Элиас
2. Перерыв
3. Уно
4. Дурак
5. Перерыв
6. Пиковая дама
7. Солнышко
8. Аукцион артефактов

Программу можно расширять во время мероприятия через экран «Этапы». Кнопка `+ Новая игра` позволяет создать новый шаблон прямо в моменте и сразу добавить его в программу.

## Экономика

По умолчанию каждый игрок получает 5 жетонов. Игры выдают жетоны победителям, а магазин и аукцион создают основные точки расходования.

В стартовом наборе предметов есть:

- Рентген кошелька;
- Щит;
- Перенаправление;
- Карманник;
- Двойная ставка;
- Переворот результата;
- Большой чупачупс;
- Изумрудное сердце.

«Карманник» автоматически переносит жетоны от выбранной цели владельцу. «Двойная ставка» автоматически удваивает следующую награду владельца за выигранный этап. Остальные эффекты фиксируются как активные игровые правила и остаются видимыми ведущему.

## Сохранения

Есть три ячейки: `slot-1`, `slot-2`, `slot-3`.

После каждой успешной команды активная ячейка сохраняется автоматически. Перед новой записью предыдущее рабочее состояние переносится в резервную копию. Если основная запись повреждена, загрузка пробует резервную.

Экспорт версии 0.2 создаёт пакет JSON с состоянием мероприятия и библиотекой игр. Такой файл можно перенести на другой компьютер и импортировать в любую из трёх ячеек. Обычные сохранения версии 0.1 также принимаются.

## Разработка

Требования:

- Node.js 20+;
- TypeScript 5.x (`tsc`).

Команды:

```bash
npm test
npm run build
npm run verify:release
```

Сборка создаёт:

`release/ivent-system.html`

Архитектура ядра командная: интерфейс и игровые модули отправляют команды, а изменение состояния выполняет только ядро. Библиотека 0.2 располагается поверх этого ядра и регистрирует пользовательские игры через тот же игровой контракт.

## Структура

- `src/domain.ts` – модель состояния;
- `src/core.ts` – команды, журнал и отмена;
- `src/items.ts` – магазин, инвентарь и эффекты;
- `src/games.ts` – этапы и исполнительный контракт игр;
- `src/game-library.ts` – паспорта, архив, версии, обложки и перенос библиотеки;
- `src/game-library-ui.ts` – экран игр, паспорт, редактор и быстрое создание;
- `src/auction.ts` – цифровой аукцион;
- `src/storage.ts` – ячейки, резерв и базовый импорт/экспорт;
- `src/statistics.ts` – итоговые номинации;
- `src/app.ts` – основной интерфейс ведущего;
- `docs/GAME_MANIFEST.md` – эталон паспорта игры;
- `tests/` – автоматические проверки;
- `release/` – готовый автономный файл после сборки.
