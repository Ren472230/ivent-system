# IVENT SYSTEM

IVENT SYSTEM – автономная система для домашних мероприятий, дней рождения и игровых вечеров. Она связывает игроков, этапы, жетоны, магазин, предметы, аукцион, сохранения и итоговую статистику в один сценарий.

## Готовый запуск

Для проведения вечера нужен только файл:

`release/ivent-system.html`

1. Скачайте файл на компьютер.
2. Откройте его двойным щелчком в Chrome, Edge или другом современном браузере.
3. Введите название мероприятия и минимум 3 игроков.
4. Нажмите «Создать вечер».

Интернет для базовой версии не требуется.

## Базовый сценарий вечера

При создании нового мероприятия система автоматически добавляет программу:

1. Элиас
2. Перерыв
3. Уно
4. Дурак
5. Перерыв
6. Пиковая дама
7. Солнышко
8. Аукцион артефактов

Программу можно расширять во время мероприятия через экран «Этапы».

## Экономика

По умолчанию каждый игрок получает 5 жетонов. Игры выдают жетоны победителям, а магазин и аукцион создают основные точки расходования.

В стартовом наборе предметов есть:

- Рентген кошелька;
- Щит;
- Перенаправление;
- Карманник;
- Двойная ставка;
- Переворот результата;
- Большой чупачупс;
- Изумрудное сердце.

«Карманник» автоматически переносит жетоны от выбранной цели владельцу. «Двойная ставка» автоматически удваивает следующую награду владельца за выигранный этап. Остальные эффекты фиксируются как активные игровые правила и остаются видимыми ведущему.

## Сохранения

Есть три ячейки: `slot-1`, `slot-2`, `slot-3`.

После каждой успешной команды активная ячейка сохраняется автоматически. Перед новой записью предыдущее рабочее состояние переносится в резервную копию. Если основная запись повреждена, загрузка пробует резервную.

Экспорт создаёт JSON-файл состояния. Такой файл можно перенести на другой компьютер и импортировать в любую из трёх ячеек.

## Разработка

Требования:

- Node.js 20+;
- TypeScript 5.x (`tsc`).

Команды:

```bash
npm test
npm run build
npm run verify:release
```

Сборка создаёт:

`release/ivent-system.html`

Архитектура ядра командная: интерфейс и игровые модули отправляют команды, а изменение состояния выполняет только ядро. Это позволяет тестировать экономику и игровые правила отдельно от браузера.

## Структура

- `src/domain.ts` – модель состояния;
- `src/core.ts` – команды, журнал и отмена;
- `src/items.ts` – магазин, инвентарь и эффекты;
- `src/games.ts` – этапы и классические игры;
- `src/auction.ts` – цифровой аукцион;
- `src/storage.ts` – ячейки, резерв и импорт/экспорт;
- `src/statistics.ts` – итоговые номинации;
- `src/app.ts` – интерфейс ведущего;
- `tests/` – автоматические проверки;
- `release/` – готовый автономный файл.
