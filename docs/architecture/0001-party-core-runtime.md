# ADR 0001: Runtime первого релиза без фреймворка

Дата: 2026-09-15
Статус: принято для версии 0.1

## Решение

Версия 0.1 использует TypeScript и браузерный DOM API без React и Vite. TypeScript компилируется штатным `tsc` в один JavaScript-файл, а небольшой Node.js-скрипт встраивает JavaScript и CSS в один автономный HTML-файл.

Это решение заменяет разделы про React и Vite в `docs/superpowers/specs/2026-09-15-ivent-system-technical-decisions.md` именно для релиза 0.1.

## Причины

- конечный артефакт обязан запускаться двойным щелчком через `file://`;
- базовая система должна работать без интернета и без сервера;
- у версии 0.1 небольшой интерфейс ведущего и отсутствует многопользовательский клиент;
- нулевое число runtime-зависимостей уменьшает риск поломки автономного HTML;
- ядро остаётся полностью отделённым от интерфейса, поэтому будущий переход на другой UI-слой не потребует переписывать доменную логику.

## Последствия

Плюсы:

- один файл релиза;
- быстрый локальный запуск;
- простая отладка;
- минимум зависимостей;
- высокая переносимость.

Ограничения:

- DOM-разметка версии 0.1 управляется вручную;
- при переходе к телефонам игроков и нескольким синхронным клиентам UI-слой нужно пересмотреть отдельным ADR.

## Условие пересмотра

Решение пересматривается при старте многопользовательской версии с телефонами игроков либо когда ручное управление DOM начинает заметно тормозить разработку новых экранов.
